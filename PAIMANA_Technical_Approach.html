2 Core Technical Features

Feature 1 — AI Delay Risk Prediction

XGBoost SHAP scikit-learn
AspectDetail
AlgorithmXGBoost Binary Classifier (binary:logistic)
Input Featuresland_acquisition_pct, milestone_slippage_count, financial_progress_gap_pct, pending_clearances_count, contractual_issues_count, months_elapsed
OutputCalibrated delay probability (0–1)
ExplainabilitySHAP TreeExplainer → top 5 risk factors with human-readable descriptions
Hyperparameters120 estimators, max_depth=3, learning_rate=0.06, subsample=0.9
Training Data2,500+ Indian infrastructure projects with labelled delay outcomes

Pipeline:

Raw Project Data → Feature Engineering → XGBoost predict_proba → SHAP Explain → Top Risk Factors

Feature 2 — Historical Similarity Engine

k-NN StandardScaler OneHotEncoder
AspectDetail
Algorithmk-Nearest Neighbors (Euclidean distance, brute-force)
PreprocessingStandardScaler (numeric) + OneHotEncoder (categorical: sector, state)
Engineered Featurescost_overrun_percentage, financial_physical_gap, milestone_delay_ratio, project_age_ratio
Feature WeightingDomain-tuned: milestone_delay_ratio (2.5×), land_acquisition_pending (2.0×), funding_issue (2.0×)
OutputTop-k similar historical projects + aggregated evidence statistics

Pipeline:

Project Features → Feature Engineering → Scale + Encode → Feature Weighting → k-NN Search

6 Security Architecture

  • Bearer Token Authentication — SHA-256 hashed token registry, loaded once at startup
  • Role-Based Access Control (RBAC) — Roles: admin, analyst, viewer
  • Permission-gated endpoints — Routes declare required permissions, not raw token checks
  • CORS policy — Restricted to application origins only
  • Designed as a seam — Swappable to OIDC/JWT without modifying any route handler

7 Key Design Principles

1
Deterministic & Auditable
Identical inputs → identical outputs. Every threshold lives in a config file. No randomness in production inference.
2
Explainability First
SHAP for ML predictions; template-based rationale for interventions; geometry-derived reasons for GIS flags.
3
Separation of Concerns
ML models → services → API routes → frontend. Each layer has a single responsibility.
4
Graceful Degradation
If any service (ML, GIS, similarity) fails to load, the app starts in degraded mode and reports exactly what's unavailable.
5
No Silent Repairs
GIS geometry is rejected, not silently fixed. Document extraction reports low confidence, not a guess.
6
Domain-Weighted Features
Similarity engine weights features by their empirically validated association with delay outcomes in historical data.
